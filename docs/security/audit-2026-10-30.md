# Security & correctness audit — 2026-10-30 (Phase 3)

**Scope:** `5052ced..9819024`, all Phase 3 work:
- migrations `20261030000100`–`0600`
- the crm, field, orders, inventory, approvals, catalog and offline modules
- their routes
- the shell changes

**Method:** an independent reviewer worked from the code alone. DB findings were reproduced against PostgreSQL 16 (PGlite, on which all existing suites pass).

**Result:** 10 findings (7 confirmed, 3 plausible) and one follow-up raised while fixing. **All fixed.**

Every fix has a regression test that fails without it. This was checked by running the suites with the fix migration removed, and by reverting the logic files for the unit tests.

| # | Severity | Finding | Fix | Test |
|---|----------|---------|-----|------|
| F1 | Medium | Customer-specific price lists (and their prices) readable by every `catalog.price.read` holder, including reps who cannot see that customer | Policies use `catalog.readable_price_list_ids()`. Customer lists are readable only with a global `catalog.price.manage` grant or for a customer in scope. | 25 |
| F2 | Medium | A discontinued variant or product could still be submitted and reserved | `NOT_SELLABLE` at pricing (draft and submit) and at reserve | 25, unit `orders-logic` |
| F3 | Med-Low | Quarantine stock became sellable through an ordinary transfer, with no control | New permission `inventory.quarantine.release` (D-13), checked at create and receive. UI warns and disables the choice. | 25, unit `inventory-logic` |
| F4 | Low-Med | After cancelling a customer price-list assignment, re-assigning it always failed (range error) | Cancelled rows are skipped in the overlap check | 25 |
| F5 | Low | DEFAULT price list could be given a future start, so every order failed `NO_PRICE` | DEFAULT must start on or before today (Cairo) | 25 |
| F6 | Low | `assign_customer_price_list` could back-date an end date that `end_customer_price_list` forbids | Same past-date rule on update | 25 |
| F7 | Low | `find_duplicate_customers` let any rep test whether a phone or clinic name belongs to a customer | Out-of-scope matches are flags only. UI: "a matching customer exists that you can't see — ask your manager". | 25, 19, unit `crm-logic` |

## Found sound

- All 20 new api views are `security_invoker`.
- Cost is gated by `catalog.cost.read`, and inventory views by `inventory.module.access`.
- New definer functions use `search_path = ''`, require permissions and scope, and internal helpers are not client-callable.
- Server actions send no prices, totals, other users' ids or scope.
- No `dangerouslySetInnerHTML`; internal links are sanitised.
- The service-role key is used only in `src/lib/supabase/admin.ts`.
- The service worker still never caches pages.
- No physical-direction CSS; translations are complete.
- No regression of the 2026-10-29 findings.
